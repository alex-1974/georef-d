# Examples

The examples are deliberately domain-neutral. They show how a consumer owns
the meaning of spaces and supplies the transformation mathematics.

- `static-space`: compile-time space definition and affine transformation.
- `runtime-graph`: runtime spaces, graph registration and prepared path use.
- `custom-transform`: consumer-owned transformation mathematics and bounds.

Run an example from its directory with:

```sh
dub run --compiler=dmd --force
```
